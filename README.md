# Solar-System-Clock  
Model  
  
The clock model is a representation of the solar system planetary motions.  
Even though it is not calibrated per se (all planets start from the same position) the orbit and local axis timing is calibrated.  
  
It currently works at 48 earth years per day in real time.  
  
The model has a symmetric pair, hinting to the probable corelation with beings.  
It also blinks at 5-3 s intervals. (human blinking)
